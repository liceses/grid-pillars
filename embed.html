嵌入方式

零依赖 · 单文件 · 一段 script 就能用
<!-- 1. 引入组件（单文件、零依赖、可离线） -->
<script src="gridpillars.js"></script>

// 2. 挂到任意容器上：自动适配尺寸 / 离屏暂停 / 尊重 reduced-motion
var gp = GridPillars.create(document.querySelector('#box'), {
  mode: 'data', palette: 'slate', legend: true, fit: true, maxDpr: 1.75
});

// 3. 喂数据 + 收点选：柱子高度就是 value
gp.setData([{ id:'deepseek', label:'DeepSeek', value:0.86, color:'#4D6BFE' }, …]);
gp.on('pick', function(item){ selectRow(item && item.id); });
生命周期：play() / pause() / resize() / destroy()；配置：getConfig() / applyConfig()；其它：setMode / setPalette / preset / exportPNG。
