# GRID PILLARS · 无限网格柱阵

浅色瑞士国际风格：近白纸面、无衬线、严格网格、1px 细线、方角、单一强调色。
地面是无限延伸的网格，**每一个格子本身升起成为一根柱子**，柱顶平贴一个图标。

```
gridpillars.js   组件本体（零依赖、原生 WebGL2，可单独拿走）
index.html       展示页（全屏 3D + 贴网格的瑞士版式 UI）
embed.html       嵌入示例（同一组件放进浅色产品后台）
```

---

## 1. 四条硬要求，逐条落实

| 要求 | 做法 |
|---|---|
| 柱子就是那个格子 | 柱体不做收分（straight prism），柱底边长 = 格距 × 0.999，四条侧棱精确落在格线上：**无缝、无叠、无错位**（留 0.1% 只为避免相邻共面 z-fighting） |
| 图标平贴柱顶 | 图标是柱顶面上的一个水平四边形贴片，尺寸 = 格距 × 0.80，抬升 0.004 防止与顶面打架；不再用 billboard |
| 看到无限屏幕 | 画布全屏无边界；地面是一块跟随相机的着色器网格，一直铺到画面边缘与地平线，用雾融进纸面 |
| 浅色瑞士风 | 5 套配色，默认「瑞士」：纸面 #F6F6F4 / 柱体石墨 / 网格灰阶 / 强调色 #E30613；扁平着色（每个朝向一个明度），无高光、无边缘光、无辉光、无倒影、无光柱、网格不脉动 |

**页面 UI 也按同一套网格做**：12 列版式网格（按 `G` 显示/隐藏，红色细线为列、灰线为基线）、Helvetica 系无衬线、全方角、1px 细线、红点 + 大写小字标签；标题块、样本表、算法竖排、工具竖排、底部两条工具带全部贴在网格上。

## 2. 组件用法

```js
var gp = GridPillars.create(el, {
  preset:'awaken',        // 9 套预设（各自带算法 + 参数 + 取景）
  mode:'scan',            // 15 种模式（14 算法 + 数据柱）
  palette:'swiss',        // swiss | deep | neon | amber | aurora | slate
  fit:true,               // 按"内容包围盒 + 容器宽高比"自动取景（嵌产品用）
  legend:true,            // 内置图例
  flat:true, colorMode:'auto',   // 扁平着色 / 柱色跟随配色（mono）或图标主色
  maxDpr:2, quality:'auto', autoPause:true
});
gp.setData([{ id:'deepseek', label:'DeepSeek', value:0.86, color:'#4D6BFE' }, …]);  // 柱高 = value
gp.on('pick', function(item){ /* 点柱子 / 点图例，联动产品 UI */ });
gp.setMode('ripple'); gp.setPalette('neon'); gp.preset('life');
gp.play(); gp.pause(); gp.resize(); gp.destroy();
gp.getConfig(); gp.applyConfig(cfg); gp.exportPNG();
```

**展示页操作**：拖拽旋转 · 滚轮缩放 · `B` 画笔升降 · `Shift`+拖拽临时升降 · `1`–`0` 切算法 · `G` 版式网格 · `P` 海报模式 · `H` 隐藏界面 · `?` 说明 · 右侧竖排开四个抽屉（预设 / 参数 / 外观 / 配置）。

## 3. 三层控制 + 数据层

- **算法层**：14 种算法逐格给出目标高度（正弦波 / 涟漪 / 螺旋 / 心跳 / 柏林噪声 / 元胞自动机 / 随机雨 / 扫描线 / 双波干涉 / 多米诺 / 涡旋 / 编织 / 全阵呼吸 / 手动）。
- **数据层**：「数据柱」模式下每根柱子是一条数据；`dataLayout:'line'` 是一排（3D 柱状图），`'ring'` 是一圈；`dataNormalize` 把当前这批数拉到可视区间（图例仍显示真实值）。
- **手动层**：画笔写入的高度与算法取 `max`。
- **缓动层**：指数缓动逼近目标，升起/回落速度分开调，切换算法不突跳。
- 地面用一张 64×64 高度场纹理做「升起处地面压暗」，替代暗色主题里的辉光。

**无限延伸**：柱子只维持 96×96 活动补丁，跨格时把 `heights` / `manual` / `heightBytes` 三张表一起平移重定中心，所以走到哪里都有柱子且不跳变。

## 3.5 音乐响应模式（跟随系统正在播放的声音）

**怎么用**：右侧竖排第 4 个图标 ♫ → 点「连接系统声音」→ 浏览器弹出来源选择，**选「标签页」或「整个屏幕」并勾上「分享标签页音频 / 分享系统音频」** → 柱阵立刻跟着声音动。
Chrome / Edge 支持最好；Firefox / Safari 用面板里的「改用麦克风」。

**声音从哪来**：平台 API `getDisplayMedia({video:true,audio:true})` —— 拿到的是**你选择的那个标签页 / 窗口 / 整个屏幕**正在播放的输出声，不是麦克风拾音、也不需要上传音频文件。
> 注意两个坑（都已处理）：① **绝不能传 `preferCurrentTab`** —— 那会让浏览器默认选中本页，抓到的就是**网页自己的声音**（通常还是静音）；② 现在已经用 `selfBrowserSurface:'exclude'` 把本页从选择器里排除，并传 `systemAudio:'include'` 让"分享系统音频"出现在选择器里。想抓**整个系统**的声音就选「整个屏幕」+ 勾「分享系统音频」（Windows 上 Chrome/Edge 支持）。
> 连上后若连续 4 秒没有电平，面板会提示"没听到声音：多半选错来源或没勾分享音频"。`video:true` 是规范要求（不给视频轨会直接抛错），视频轨不接任何 sink、不额外渲染。

**听到什么 → 柱子怎么动**（"一眼看出在跟音乐"的关键）

| 音频特征 | 映射到柱阵 |
|---|---|
| 16 个对数频段（40Hz–16kHz） | **16 个同心环**，半径 `(i+0.5)/16 × spread`，每环高度 = 该频段能量（带噪声门 + 幂曲线，安静处就是平的） |
| 低频 / 整体响度 | 中心最强 → 重低音把中间整块顶起来 |
| 频谱重心（亮度） | 高频越亮，外环越活跃（0.55–1.15 加权） |
| 频谱通量突增（重拍） | 触发 `impulse`：**全阵一次整体抬升** + 一圈**向外推的冲击波**，约 160ms 衰减 |
| 无信号 / 未连接 | 回落到 0.04 的慢呼吸，明确是等待态 |

**实现分工（不重复造轮子）**
- FFT / 窗函数 / 特征提取 → **[meyda](https://github.com/meyda/meyda) 5.6.3**（MIT），vendored 到 `vendor/meyda.min.js`（15.7 KB，浏览器 UMD，经典 `<script>` 加载 → 保持零构建、离线、双击即用）
- 抓系统声 → 平台 API，不需要库
- onset / BPM → 在 meyda 的幅度谱上做频谱通量 + 滚动均值阈值（`flux > 1.5×近 1s 均值 且 > 0.06`，110ms 不应期）；BPM 取 onsets 间隔中位数，仅用于显示
  *为什么不用 `realtime-bpm-analyzer`：v5 基于 AudioWorklet，`addModule` 在 `file://` 下会被拦，与"双击即用"冲突*

**接口**
```js
var tap = GridPillars.createAudioTap({ source:'display', target: gp });  // 或 'mic'
tap.start();          // 必须在用户手势里调用
tap.state;            // { status, source, error, bpm }
tap.stop();
// 也可以自己喂帧（任意音源 / 离线分析 / 自动化测试）：
gp.setAudioFrame({ bands:Float32Array(16), level, bass, mid, high, bright, flux, beat, bpm });
GridPillars.audioSupported();   // { secure, display, mic, meyda, audioContext }
```

**边界**：漏勾"分享音频"→ 面板直接提示重新选择；拒绝授权 → 提示换麦克风；连上后 4 秒无电平 → 提示"没听到声音，多半选错来源"；用户点浏览器自带的"停止共享" → 自动断开；DSH 卡片是沙箱 iframe，会拦屏幕捕获 → 用右上角「浏览器打开」再连。

## 4. 修掉的两个真 bug

**① 深度缓冲从未被清空。** `gl.clear(DEPTH_BUFFER_BIT)` 受 `depthMask` 约束：之前先 `depthMask(false)` 再 clear，清深度其实是空操作，上一帧柱子留下的深度会把近处地面剔除 —— 表现为地面时有时无、"柱子像挂在空中"。现在改成 `depthMask(true)` → clear → `depthMask(false)`。

**② 能看见"柱阵的边"。** 柱子只存在于一块随相机移动的活动补丁里，早先补丁边缘（离相机 ~102 单位）落在雾的可见范围内，越过它只剩空网格；视角一转边界扫过，边缘新格子从 0 长起来 —— 看起来就像"柱子随视角变化"。现在：
- 补丁从 64×64 加到 **96×96**；
- **柱阵用一套更短的雾**（在补丁边界之内收干净），而**地面网格保持长雾** → 柱阵淡进纸面、边界不可见，网格仍然铺到地平线。

> 用 `gp.sample(cx, cz)` 验证过：换 51 格的视角后，仍在补丁内的 63 个世界格高度**完全一致**（0 个变化）—— 图案锚定在世界坐标上，不跟相机跑。

## 6. 已知限制

- 内置 6 个模型徽标是运行时绘制的**简化矢量图形**，非官方素材；替换只需改 `BUILTIN` 里的绘制函数，或用「上传图片」。
- 图标是平贴贴片：从背面看会上下颠倒（贴纸的物理事实）。
- 柱色默认跟随配色（单色石墨），想要品牌色把 `colorMode` 设为 `'icon'`。
- 补丁边缘在雾之外，但把「可视距离」拉到最大时边缘会露出来。
- 音乐响应**必须由用户点一次授权**（浏览器不允许网页静默监听系统声）；要"无感全局监听"只能做浏览器扩展或本地包装应用 —— 那时同一套 `setAudioFrame` 接口可以直接复用。
- meyda 内部用 `ScriptProcessorNode`，Chrome 会打一条 deprecated 警告（功能正常）。
