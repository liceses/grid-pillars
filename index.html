Grid Pillars

无限延伸的网格地面 · 每个格子本身升起成为柱子 · 柱顶平贴图标 · 14 种升降算法 + 数据柱。

操作

  • 左键拖拽旋转 · 右键拖拽平移 · 滚轮缩放
  • 单击：把涟漪 / 螺旋 / 心跳的中心移到那一格
  • B 开画笔后左键拖拽升降柱子；右键擦除
  • Shift+拖拽：任何模式下临时升降
  • 触屏：单指旋转 · 双指捏合缩放并平移

快捷键

  • 1–90 切换算法模式
  • 空格 暂停 · B 画笔 · C 巡航
  • R 重置 · F 全屏 · G 版式网格
  • P 海报模式 · H 隐藏界面 · ? 本说明

它是怎么构成的

  • 柱子 = 格子：柱底的边长精确等于格距，四条侧棱落在格线上，不收分、不留缝。
  • 图标平贴：图标是柱顶面上的一个四边形贴片（含 1% 抬升避免与顶面打架），不是悬浮面片。
  • 无限网格：地面是一块跟随相机的着色器网格，一直铺到画面边缘与地平线，用雾融进纸面。
  • 三层控制：算法层给目标高度 → 手动层取 max → 缓动层逼近。

作为组件嵌入

var gp = GridPillars.create(el, { mode:'data', palette:'swiss', fit:true, legend:true });
gp.setData([{ label:'DeepSeek', value:0.86, color:'#4D6BFE' }, …]);
gp.on('pick', function(item){ /* 联动你的界面 */ });
